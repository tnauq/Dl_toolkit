## 2. The question, and why it came first

`dl-patch` writes vdata back. Two routes existed:

- **surgical text edit** — rewrite the bytes around the target value, leaving
  everything else untouched
- **parse → model → re-serialize** — VRF reads it, we change a leaf, VRF prints
  it back

The developer chose the parse route deliberately, on the reasoning that a full
toolkit needs a real writer eventually and the cheap scalars-only case is the
best place to find its sharp edges.

**But whether VRF could already serialize KV3 text was unverified.** Building on
that assumption is precisely the failure `FINDINGS` correction 1 records. So a
throwaway probe ran first: parse a real hero vdata, serialize it straight back
with no edit, diff.

**Result: usable.** Semantically lossless, cosmetically reformatted. We do not
have to write a serializer. Details in the FINDINGS additions.

## 4. The design decision worth remembering

VRF reformats on write, so **byte-identity against the original is
impossible**. The assertion was recovered anyway by diffing against a **no-op
round trip** instead: reformatting is constant on both sides, so the check
reduces to "exactly one line differs". Result on a real 116,786-line hero file:

```
38c38
< EMaxHealth = 780.000000
> EMaxHealth = 1234.000000
```

That is the guarantee the surgical route was wanted for, obtained through the
parse route.

## 5. Process failures this session — both mine, both avoidable

**Three compile failures from writing against an unread API.** CS0102, then
CS0266, then CS0103 eight times. The first probe *tried* to dump VRF's surface,
but its type filter matched only names containing `KV3`, which excluded
`KVObject`, `KVValue` and `KVType` — exactly the three needed. Widening the
dump answered everything in one run and the code compiled first try after.

**Rule to carry:** a probe against a library must dump the surface it is about
to be used THROUGH, not the surface that shares its name. This is correction 1
repeating; it is now correction 3.

**A workflow input cost a revision.** `workflow_dispatch` inputs are read from
the default branch and re-runs replay old inputs. For a probe run twice and
deleted, hardcode the value.

## 6. Framework split — new, and it will spread

`ValveResourceFormat` 12.x is **net9.0 only**. `Deadlock.Patch` and the probe
are net9.0; everything else is net8.0. A net9.0 project can reference a net8.0
one, not the reverse — which is why `Deadlock.Patch` carries a local envelope
instead of referencing `Deadlock.Contracts`.

**If a second shipping tool needs VRF, migrate the whole solution.** Do not
accumulate exceptions.
