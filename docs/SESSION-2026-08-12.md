## 1. Headline

**The chain is closed, end to end, from a phone:**

```
plan -> dl-patch batch -> overlay -> resourcecompiler -> .vdata_c
     -> dl-patch pack   -> addon VPK
```

Every link is `[V-CI]`. `loop.yml` asserts the whole thing in one run and
uploads `dist/pak01_dir.vpk` as an artifact — a real, downloadable mod file
produced without a desktop.

**The ceiling is unchanged.** D7 still holds: this is a *structurally valid*
addon. Whether Deadlock loads it, and whether it tolerates VRF's reformatting,
needs hardware and is untested.

## 3. Decisions — settled, do not relitigate

### Framework

| | |
|---|---|
| **`Deadlock.Contracts` is multi-targeted `net8.0;net9.0`** | Patch needs net9 (VRF 12.x), the rest is net8, and Contracts sits under both. This is NOT the "accumulating exceptions" the earlier note warned about — that warning is about shipping TOOLS on mixed frameworks. Contracts references nothing of ours, which is exactly the assembly where multi-targeting is free. Collapsing to single-target net9 stays a one-line change per csproj. |
| **Patch (net9) references Format (net8)** | Legal and requires no migration. |

### batch — seventeen answers, all in `TOOLING-dl-patch.md`

Summarised: guards **mandatory** (explicit `null` opts out), numbers compared
after **6dp normalisation**, all documents held **in memory** and written only
after every guard passes, `--out-root` **required and separate** (output is an
overlay), duplicate path or duplicate file is an **error**, apply in plan order
and **emit sorted**, `--source-build` **required**, guard failure is exit **7**,
a vanished guarded path is **also 7**, unknown fields and versions **refused**,
`--dry-run` evaluates **everything**, file cap **32**, **all** failures reported,
**every** planned file appears in the envelope.

### diff

| | |
|---|---|
| **A subcommand, not a new assembly** | `Kv3Document.cs` is the only file that touches VRF and that invariant is worth more than tool-name purity. |
| **Semantic, not textual** | Compares parsed values, so reserialisation yields zero differences. A textual diff would report most of the file. |
| **Arrays are opaque** | Length change registers; an element edit does not. Array elements have no dotted path, so naming them would emit paths dl-patch refuses. Stated in `--help`. |
| **Exit 1 = files differ** | `Contracts.Exit.ExpectedFailure`, used for exactly its stated meaning. `ok` stays true and `errors` stays empty: a difference is a RESULT. This spends the code batch had reserved for a future `--check`. |

### pack

| | |
|---|---|
| **Archive writing stays in `Deadlock.Format`** | CI enforces the layer boundary; pack is a front end over `VpkWriter`. |
| **Entries keyed relative to `--in`**, forward-slashed | `[I]` — consistent with gameinfo's mounts and the compiler's write path, unconfirmed against a running game. `--prefix` exists if it proves wrong. |
| **`--source-build` required** | D2. A VPK is the most shippable artifact this toolkit makes. |
| **`--verify` re-reads and checks every CRC32** | Failure is exit **8** — the tool worked and the RESULT is untrustworthy, the one case where shipping anyway is harmful. |

## 6. Process — a fourth lesson

The existing three (survey before building; cap the yak-shave; probe the
surface you will actually use) all held. Add:

**4. Dump the real file before writing code that depends on its shape.**

This session had one compile error and four workflow bugs. Every one came from
inferring a shape instead of reading it: a hand-typed `KVValue?`, a regex
assuming `m_fl*` at two tabs, a path-walker that mishandled arrays of objects,
and a compiler invocation guessed at three times before anyone read
`gameinfo.gi` — which answered it immediately and unambiguously.

The tool code was correct in every one of those runs. The failures were in the
scaffolding around it, written against imagined surfaces.

**Corollary, from the pack bug:** a green run is not a correct run. The first
`loop` run passed every assertion while packaging the wrong file. Assertions
prove what they ask; carry identity checks across every stage boundary, not
just the interesting one.
