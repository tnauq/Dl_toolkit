# Can you send me one file from Deadlock?

It's a small text file in the game folder. Takes about a minute, doesn't
change anything, nothing to install.

## Step 1

Open Steam. Find **Deadlock** in your library.

## Step 2

Right-click it → **Manage** → **Browse local files**.

A folder window opens.

## Step 3

Double-click into the folder called **game**.

Then double-click into the folder called **citadel**.

## Step 4

Look for a file called **citadel.fgd**

(It may just show as **citadel** with a gear or blank icon — that's the one.
If you see a "Type" column, it says FGD File.)

## Step 5

Right-click it → **Send to** → **Mail recipient**.

Or drag it straight into an email. It should be a few MB at most.

That's it — thank you!

---

## If you can't find it

In the folder from step 2, there's a search box in the top-right corner.
Type **citadel.fgd** and press Enter. Wait a few seconds and it'll turn up.

## If it's too big to email

Drop it in Google Drive, Dropbox or WeTransfer and send the link instead.

## While you're there — a bonus, only if it's easy

In that same **game\citadel** folder there may be other files ending in
**.fgd**. If you see any, send those too. If not, don't worry about it —
citadel.fgd is the one that matters.

**Please don't** try to copy the whole game folder. It's enormous (tens of
gigabytes of .vpk files) and none of that is needed.
