# Sending me the Deadlock config files

About 10 minutes. Nothing gets installed, nothing changes, the game is
unaffected. You're making a zip of some settings files and sending a link.

## Step 1 — open the game folder

Open Steam. Find **Deadlock** in your library.

Right-click it → **Manage** → **Browse local files**.

A folder window opens.

## Step 2 — go into game, then citadel

Double-click the folder called **game**.

Then double-click the folder called **citadel**.

## Step 3 — sort by size

At the top of the window, click **View** → **Details** (skip if the files
already show in a list with columns).

Now click the **Size** column heading twice, so the biggest files are at the
top.

## Step 4 — select everything, then un-select the big ones

Press **Ctrl + A** to select everything in the folder.

Now, holding **Ctrl**, click on each of the huge files at the top of the
list to un-select them. These are the ones named **pak01_...** and they'll
be several GB each.

Everything you leave selected should be small — a few MB at most.

## Step 5 — zip it

Right-click any of the still-selected files → **Send to** → **Compressed
(zipped) folder**.

Windows 11: it may say **Compress to** → **ZIP file** instead.

A new zip appears in the folder. Rename it **citadel** if you like.

## Step 6 — check the size

Right-click the new zip → **Properties**. Look at the size.

- **Under 500 MB** — perfect, go to step 7.
- **Several GB** — a pak01 file slipped in. Delete the zip and redo step 4.

## Step 7 — send it

Drag the zip into **Google Drive** (drive.google.com), wait for it to
finish, then right-click it there → **Share** → **Copy link**, and send me
that link.

Or use WeTransfer (wetransfer.com), which needs no account — drag the zip
in, enter my email, send.

That's it. Thank you!

---

## Notes

**Don't zip the whole Deadlock folder.** It's about 34 GB and would take
hours to upload, and none of that bulk is needed.

**If step 4 is fiddly**, just grab this one file on its own instead and
email it: **citadel.fgd**, in that same citadel folder. It's the most
important thing in there by a wide margin, and everything else is a bonus.

**What this is:** the editor's definition files — text that lists what the
map editor knows about. Not game code or artwork, and not going anywhere
public. It's for checking a fan map project against the real definitions.
